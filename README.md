# Буквар

Безплатна програма за Windows за разпознаване на текст (OCR) от сканирани документи, PDF файлове и снимки. Свободен софтуер с отворен код, лиценз MIT.

## Какво може (версия 0.1)

- Отваря **PDF**, **PNG, JPG, TIFF (и многостраничен), BMP, GIF, WebP**. Може и с плъзгане на файлове в прозореца.
- Разпознава **български и английски** едновременно. В инсталатора има още руски, украински, сръбски, македонски, немски, френски, италиански, испански, турски, гръцки и румънски.
- **Автоматично завърта** обърнати страници и **изправя наклонени** сканове.
- Записва:
  - **търсим PDF**: оригиналната страница плюс невидим текст, по който се търси и копира;
  - **Word (DOCX)**: абзаци, заглавия, нова страница за всяка страница;
  - **текст (TXT)**.
- **Формуляри:** квадратчетата за отметка стават ☐ и ☒ в текста. Подписите и ръкописът (синьо мастило) не дават безсмислици, а се отбелязват като [ръкопис]. Редовете от точки за попълване („……“) не объркват разпознаването.
- Текстът се **поправя на ръка** преди запис в DOCX/TXT.
- Показва **увереност** за всяка страница, за да знаете кои да проверите.
- Поправя типичната грешка при смесен текст, когато кирилицата се чете като латиница („ce Ha“ → „се на“).
- Обработва **няколко страници паралелно**.
- **Команден ред** `bukvar-cli` за пакетна обработка на цели папки.
- **„Разпознай с Буквар“** в менюто на десния бутон в Windows Explorer (по избор при инсталиране).

## Инсталиране

Изтеглете `Bukvar-Setup-x.y.z.exe` от страницата **Releases** и го пуснете. Не са нужни администраторски права.

> Windows може да покаже „Windows защити компютъра ви“, защото инсталаторът още не е подписан. Натиснете **Повече информация → Изпълни въпреки това**.

## Команден ред

```
bukvar-cli скан.pdf                            → скан.ocr.pdf до оригинала
bukvar-cli C:\Сканове -r -f pdf,docx -o C:\Готови
bukvar-cli снимка.jpg -l bul+eng+rus -f txt
bukvar-cli --list-langs
```

`bukvar-cli.exe` е в папката на програмата (обикновено `%LOCALAPPDATA%\Programs\Bukvar` или `C:\Program Files\Bukvar`).

## Изграждане на инсталатора

### Вариант А: автоматично в GitHub (без нищо на компютъра)

1. Създайте хранилище в GitHub и качете файловете на проекта.
2. GitHub Actions изгражда инсталатора при всяка промяна: раздел **Actions → Windows инсталатор → Artifacts → Bukvar-Setup**.
3. За официално издание: създайте таг `v0.1.0`. Инсталаторът се появява в **Releases**.

### Вариант Б: на вашия компютър с Windows

1. Инсталирайте [Python 3.12](https://www.python.org/downloads/) (отметнете „Add python.exe to PATH“).
2. Щракнете два пъти върху **`build.bat`**. Скриптът сам инсталира Tesseract и Inno Setup през `winget`, ако липсват.
3. Готовият инсталатор е в `Output\Bukvar-Setup-0.1.0.exe`.

### Стартиране от изходния код (за разработка)

```
pip install -r requirements.txt
python run_gui.py
```

Нужен е инсталиран Tesseract ([UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)) с български език.

## Устройство

| Файл | Какво прави |
|---|---|
| `bukvar/engine.py` | зареждане, завъртане/изправяне, разпознаване, запис в PDF/DOCX/TXT |
| `bukvar/layout.py` | формуляри: квадратчета, ръкопис, редове от точки |
| `bukvar/textfix.py` | поправка на объркана кирилица/латиница |
| `bukvar/app.py` | графичният интерфейс (Qt) |
| `bukvar/cli.py` | команден ред |
| `bukvar.spec`, `build.ps1`, `installer.iss` | изграждане на .exe и инсталатор |
| `tests/` | тестови сканове и измерване на точността |

Тестове: `python tests/make_samples.py samples && python tests/run_engine_test.py samples out` и `python tests/test_forms.py`

## Промени

### 0.2.0
- Разпознаване на квадратчета за отметка (☐/☒) във формуляри.
- Подписи и ръкопис в синьо мастило: махат се преди разпознаването и се отбелязват като [ръкопис].

- Повече поправки на объркана кирилица/латиница: „HE“ → „НЕ“, „KCK“ → „КСК“, „JIA“ → „ДА“, „Ne ЕП-2“ → „№ ЕП-2“, „P-n c-p“ → „Р-л с-р“.
- По-компактен Word документ.
- Настройка „Формуляри“ (включена по подразбиране) и `--no-forms` за командния ред.

## Сравнение с ABBYY FineReader

Буквар се справя добре с чист печатен текст, договори, книги и писма. Там FineReader все още е по-силен:

- сложни таблици и многоколонни страници (вестници, списания) с точно запазено оформление в Word;
- ръкописен текст и много лоши сканове;
- редактор с проверка на несигурните думи една по една;
- сравнение на документи, попълване на формуляри.

## План за следващите версии

1. Оцветяване на несигурните думи в текста и бърз преход между тях.
2. Разпознаване на таблици, които стават истински таблици в Word и Excel.
3. Избор на област от страницата (само текст, само таблица, без картинки).
4. По-точен двигател по избор (Surya/PaddleOCR) за трудни сканове.
5. Директно сканиране от скенер (WIA/TWAIN).
6. MCP сървър за работа с AI агенти.
